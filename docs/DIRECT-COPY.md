# 직접 복사 배포 검증

CopyPaste ZIP은 사용자가 프로그램을 실행하지 않고 게임 루트에 Data 폴더를 병합·덮어쓰는 완성 패치입니다. 수정 25파일과 추가 8파일만 포함하며, 33파일의 해시는 기존 검수 패치와 같습니다. 압축 전 게임 파일 합계는 58,525,099바이트, ZIP은 16,475,510바이트입니다.

가장 큰 수정 파일은 resources.assets(29,698,280바이트)와 영어 이미지 번들(17,932,785바이트)입니다. 이 Unity 컨테이너에는 번역·폰트·수정 이미지 외 원래 데이터도 남아 있습니다. 파일 내부의 미수정 객체를 없애면 게임 참조가 깨지므로 컨테이너 단위로 포함합니다. 게임 전체나 실행 파일, 별도의 미수정 파일, 원본 백업, 세이브, 로컬 작업 경로는 패키지에 추가하지 않습니다. 검토한 로컬 프로젝트 안내에서는 별도의 재배포 금지 조항이 발견되지 않았으며, 이 기록은 포괄적인 라이선스 보증을 뜻하지 않습니다.

검증된 원본 대상 25파일의 격리 복사본에서 ZIP을 풀어 파일 복사만으로 설치했습니다. 33개 결과 해시가 일치했고, Unity 파일 23개 파싱, UI 번역 225개, 서식 태그를 정규화한 대사 번역 1,484개, 영어 카탈로그 경로, 한국어 폰트 및 이미지 런타임 참조를 확인했습니다. 원본 Data 폴더 전체를 백업하고, 패치 Data 폴더 이름을 바꾼 뒤 백업을 복사하는 README 절차로 원본 25파일 복원과 추가 8파일 부재를 확인했습니다. 무관한 파일과 세이브 검사용 표식도 보존됐습니다.

완전한 게임 실행본은 현재 확인한 설치 경로에 없으므로 실제 게임 실행 검증은 하지 않았습니다. 정적 로딩 검증을 실제 플레이 검증으로 해석하지 마십시오. 자세한 결과는 `direct-copy-validation.json`, 배포 파일 명세는 `direct-copy-contents.json`에 있습니다.

유지보수자는 검수된 33파일의 루트를 `python tools/build_copy_payload.py --files <검수된 파일 루트>`에 전달해 배포 입력을 만듭니다. 이 명령은 사용자 설치 절차가 아닙니다. 저장소 전송 한도 때문에 `copy-package-parts`에 입력 조각을 보관하며, `tools/build_downloads.py`가 해시를 검증해 단일 CopyPaste ZIP으로 조립합니다. 사용자는 `downloads/Cockspur-Korean-CopyPaste.zip` 하나만 다운로드합니다. 빠른설치 ZIP은 기존 파일의 바이트와 해시를 그대로 유지합니다.
